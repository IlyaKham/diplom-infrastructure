## Как показать результаты Terraform

Команды помощника выполнялись в фоне. Для снимка можно открыть свой PowerShell и вывести подготовленную выдержку из журналов:

```powershell
cd C:\Users\khamu\Diplom_YC
Get-Content -Encoding UTF8 .\infrastructure\docs\evidence\01-terraform-results.txt
```

Файл формируется из фактических выводов Terraform. Он не выполняет операции с облаком. На снимке должны читаться три итога:

- удалены 4 ресурса;
- заново созданы 4 ресурса;
- итоговый план сообщает `No changes`.

Удаление выполнялось через проверенный сохранённый план `terraform plan -destroy` с последующим `terraform apply` этого плана. В отчёте не нужно выдавать это за ручной запуск другой команды. Полные журналы хранятся рядом с выдержкой в `docs/evidence/`.

## Что не включать в изображения

Не показывай `secrets.local.ps1`, закрытый JSON-ключ, OAuth/IAM-токены, секретную часть статического ключа или содержимое `.tfstate`. Для подтверждения backend достаточно списка объектов бакета, настроек и результатов Terraform. Имена ресурсов, их ID, зоны и адреса подсетей можно оставить видимыми.
